# Archive: history, not instructions

Everything here is finished work kept for provenance:

- one-off migration and fix scripts (`import_wave*`, `fix_*`, `improve_*`, `open_*`);
- dated run reports and playtest write-ups;
- superseded plans (`alpha/LEGACY_*`) and wave handoffs (`notes/`);
- the old Goldenrod prime-agent prompt (`agent/STORY_PASS_PRIME_PROMPT.md`);
- throwaway emulator probes (`demo/`).

**Do not run these scripts.** Most mutate map data in bulk against a repo state
that no longer exists, and their paths (`plastic_ox/agent/...`, absolute home
paths) are stale. Live tools are in `plastic_ox/tools/`, and the current docs
index is `plastic_ox/README.md`. When a report here is the only record of
why something is the way it is, quote it, then put the conclusion in a live doc.

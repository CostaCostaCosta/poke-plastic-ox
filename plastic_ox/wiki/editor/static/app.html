Design workflow

Story notes

Browse a location, edit the markdown note that drives its story, key interactions, and dialogue, then export the diff as direction for an implementing agent.

How the hand-off works

  1. Open a note from the sidebar, or follow Edit this note from any wiki page.
  2. Edit the markdown. The Write tab has section jumps; Preview renders the page; Diff shows the uncommitted change; Check validates identifiers against the ROM source.
  3. Save the note. The wiki page is rebuilt so you can keep reading it.
  4. Open Direction, say what should improve, and export a bundle under plastic_ox/story/directions/. Point the implementing agent at that file.

Notes are plain markdown in plastic_ox/story/locations/. Nothing is committed for you.

Keyboard shortcuts

Ctrl + S
Save the note (⌘S on macOS)
Ctrl + Enter
Check the note without saving
Alt + 1…4
Switch Write, Preview, Diff, Direction
/
Jump to the note filter (when not typing)
?
Open this dialog (when not typing)
Esc
Close a dialog or the display panel

Every control is a native button, link, input, or textarea, so Tab, Shift+Tab, Enter, Space, and screen-reader navigation work as expected.
